# Receipt workspace frontend

React + TypeScript + Vite, Tailwind CSS and copied shadcn/ui components.

Follow [setup, review workflow, security, testing and private AWS access](../docs/frontend.md).
Run `npm ci`, `npm run dev`; open http://127.0.0.1:5173/ui/ with a backend on port 8000.
The production build is served by FastAPI at `/ui/` in the Docker image.
